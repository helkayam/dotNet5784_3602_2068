# Independence Day Task Manager

## Overview
Independence Day Task Manager is an employee management system developed in .NET, designed to provide robust access control and efficient employee data handling for Windows systems.

## Key Features
- Three-tier architecture for clear separation of concerns
- WPF graphical interface for a modern user experience
- Access control to manage user roles and permissions
- Uses MVVM design pattern for maintainable code structure
- Implements Observer and Singleton patterns
- Data management with XML and LINQ
- Multithreading for responsive performance

## Technologies Used
- .NET (C#)
- WPF
- MVVM
- XML
- LINQ
